ΥΓΕΙΑ

Πώς νιώθεις σήμερα, αν χρειαστεί γιατρός ή νοσοκομείο.

Πόσο σίγουρος/η νιώθεις σήμερα για τα έξοδα ενός θέματος υγείας;
Για ένα απλό θέμα υγείας, πού θα ένιωθες πιο σίγουρος/η;
Για κάτι σοβαρό, πού θα ήθελες να βρίσκεσαι;
Θα ήθελες να πληρώνεις ένα μέρος των εξόδων μόνος/η σου, για να είναι πιο χαμηλή η μηνιαία δόση;
Αυτό λέγεται απαλλαγή. Είναι ένα ποσό που συμφωνούμε από πριν ότι το πληρώνεις εσύ, και τα υπόλοιπα τα καλύπτει το πρόγραμμα.
Πόσο μεγάλο να είναι αυτό το ποσό;
Όσο μεγαλύτερο, τόσο πιο χαμηλή η μηνιαία δόση. Το ακριβές ποσό το βρίσκουμε μαζί.
Πόσο μεγάλο να είναι το ποσό σε κάθε νοσηλεία;
Το ακριβές ποσό το βρίσκουμε μαζί.
Ποιους θέλεις να καλύψουμε;
Η ίδια επιλογή για την απαλλαγή ισχύει για όλους.
Αν εμφανιστεί μια σοβαρή ασθένεια, θα ήθελες να πάρεις κι ένα ποσό στο χέρι, για να σταθείς οικονομικά;
Θα σε βοηθούσε ένα ποσό για κάθε μέρα που μένεις στο νοσοκομείο, για τα μικροέξοδα;

Πώς θα τα βγάλουν πέρα οι δικοί σου, αν συμβεί κάτι απρόοπτο.

Αν δεν μπορούσες να δουλέψεις για καιρό, ή αν έλειπες, θα δυσκολευόταν το σπίτι οικονομικά;
Τι θα σε ανησυχούσε περισσότερο να μείνει ακάλυπτο; (διάλεξε όσα ισχύουν)
Πόσο δυνατό «δίχτυ» θα ήθελες να έχουν οι δικοί σου;
